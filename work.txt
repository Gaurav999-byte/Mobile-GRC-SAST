## 2.4 Work Carried Out

The project focused on the design and development of an **ML-Enhanced Governance and Risk Assessment Platform for Mobile Applications using Static Application Security Testing (SAST)** techniques. The system was developed to perform automated security assessment of Android APK files by identifying common vulnerabilities, analyzing security risks, and generating compliance-oriented audit reports.

The application performs static analysis on Android APK files to detect insecure configurations, exposed attack surfaces, hardcoded secrets, insecure communication mechanisms, backup vulnerabilities, and other common Android security weaknesses. The identified vulnerabilities are further mapped with internationally recognized governance and compliance frameworks such as **ISO 27001**, **GDPR**, and **OWASP MASVS/MSTG** standards.

The backend of the system was developed using **Python** and the **FastAPI** framework. APK analysis and manifest inspection functionalities were implemented using the **Androguard** library. A custom rule-based SAST engine was designed to analyze Android application components and detect predefined vulnerability patterns.

To enhance the intelligence of the system, a **Machine Learning-assisted risk prediction module** was integrated using the **Random Forest algorithm**. The ML model predicts vulnerability severity levels and provides confidence scores for detected findings. The model was integrated using **Scikit-learn** and **Joblib** for model loading and prediction processing.

The project also includes a governance mapping engine developed using a custom JSON-based rule system that automatically associates detected vulnerabilities with relevant compliance controls and recommendations. Automated reporting functionality was implemented using **Jinja2 templates**, **XHTML2PDF**, and **python-docx** to generate professional HTML, PDF, and DOCX audit reports with graphical visualizations and compliance summaries.

A modern web-based dashboard was developed using **HTML5**, **CSS3**, **JavaScript**, and **Bootstrap-inspired responsive UI design** to provide an interactive user experience. The platform allows users to upload APK files, initiate automated scans, visualize vulnerability distributions, view ML-based risk predictions, and download detailed assessment reports.

The completed system successfully bridges the gap between traditional static vulnerability analysis and governance-oriented risk assessment by integrating SAST methodologies, machine learning-based prediction, automated compliance mapping, and professional reporting into a unified platform.
